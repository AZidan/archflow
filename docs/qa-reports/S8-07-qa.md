## Findings

### I-1 (minor): SECURITY.md and CHANGELOG list fewer event properties than ADR 005 and the code

- **Location:** `SECURITY.md:88-90`, `CHANGELOG.md:19-20`
- **Expected:** ADR 005's Consequences says both documents state the payload "in the same terms" as
  the ADR. The ADR's allow-list and the code also send `has_project`, `session_source`
  (`session_start`), `detected_by` (`command_run`), `studio_capture` (every event), and
  `installed_hosts` and `source` (`cli_install`).
- **Actual:** SECURITY.md says the events "carry the host, the host's entrypoint, whether Studio
  launched the session, the project type, Archflow version, phase and mode". It names none of the
  six properties above. It also implies `cli_install` carries the project type, phase and mode, but
  `scripts/archflow.mjs:573` sends only `host`, `archflow_version`, `installed_hosts` and `source`.
  The CHANGELOG has the same gap.
- **Impact:** None of the omitted values is identifying (each is a boolean, an enum, a host name or a
  release label). Still, the security document is the user-facing statement of what is sent, and it
  is narrower than what is actually sent. Fix: list the per-event properties, or link to ADR 005's
  allow-list.

### I-2 (minor): SECURITY.md says telemetry is "the only thing it sends anywhere", but other outbound requests exist

- **Location:** `SECURITY.md:3-5`
- **Expected:** The opening sentence should describe Archflow's outbound network activity accurately.
- **Actual:** `plugin/hooks/check-upgrade.mjs:47,56` requests
  `https://github.com/AZidan/archflow/releases/latest` from the session-start upgrade check.
  `scripts/archflow.mjs:68-98` downloads release tarballs from GitHub during `npx archflow install`.
  Neither sends user data, but both are outbound requests, and SECURITY.md mentions neither.
  This story introduced the new absolute wording "The only thing it sends anywhere".
- **Fix:** Qualify the sentence, for example "the only data it sends", and mention the upgrade check
  and the installer's release download.
