## Privacy / telemetry copy vs SECURITY.md "## Telemetry"

Each claim was checked against SECURITY.md. All are true.

- "Your code and your credentials never leave the machine; only anonymous usage events do, and you
  can turn those off" (index L586, studio.md L166-167). SECURITY sends only event metadata, never
  file contents, paths, prompts or arguments. This is the user's own framing in the subtask. Note:
  the coding agent itself sends code to its model provider. That is outside Archflow and Studio and
  is not filed.
- "on by default and never includes code, prompts, paths or project names" (L605). Matches "never
  sends project names, file paths, file contents, prompts or command arguments".
- "`/archflow:telemetry off` or `DO_NOT_TRACK=1` turns it off" (L606). Both are listed opt-outs.
  studio.md L172 adds `npx archflow telemetry off`, also listed. "Everywhere" matches "applies to
  every project on the machine" and "silences both the hooks and Studio".
- studio.md session telemetry: "which commands run, the host, version, phase and mode. Never project
  names, paths, file contents or command arguments." This is a true subset.
- studio.md Studio events: server start/open project, view as route template only, onboard/migrate/
  cut-a-release/copy action, host change. These are `studio_server_start`, `studio_page_view`,
  `studio_action` and `studio_host_selected`, and they match. "Never sends the copied text itself,
  only that a copy happened and which command it was" matches "sends only the command's name".

`docs/index.html:7, 9, 23, 98, 405, 479, 826`. Guardrail 6 in `.claude/skills/archflow-marketing/SKILL.md`

### I-3 (minor): JSON-LD no longer matches the page
`docs/index.html:99, 114, 130`. The block's own comment says "Every value here must stay true" and
that the FAQ entries "mirror … verbatim". `softwareVersion` is `"2.3.0"`, but `package.json` and
`plugin.json` are `2.4.0` and this release is v2.5.0. The FAQ answers paraphrase the visible text.
For example, FAQ 3 says "Archflow is built for it. Full comparisons: archflowai.dev/compare/…" while

and verbatim answers.

### I-4 (minor): clicking the nav logo throws and does nothing
`docs/index.html:347` (`<a href="#">`) and `docs/index.html:1431-1438`. The smooth-scroll handler
calls `preventDefault()` and then `document.querySelector('#')`. In the browser this logged
`Uncaught SyntaxError: Failed to execute 'querySelector' on 'Document': '#' is not a valid selector.`,
and the page did not scroll to the top. Expected: the logo returns to the top. The handler should
skip a bare `#`, or the logo should target an id.

### I-5 (minor): the dismiss button covers the announcement text on mobile
`docs/index.html:300-310`. At a narrow viewport (~494px CSS) the `absolute right-4` close button
sits on the last word of "…every supported coding agent". The bar has no right padding to make room
for it. Expected: the text wraps clear of the button, for example with `pr-10` on the inner row.
Cosmetic. Desktop is fine.
