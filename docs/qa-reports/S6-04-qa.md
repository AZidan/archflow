## Notes for the record (not issues against this repo)

- api-engineer reported Studio-side wording problems inside the bundle: the parked-answers dialog says "sends ... to Claude" / "continues the run", and `RUN_KEYS` lacks `resumes`. These belong to the archflow-studio repo. I did not verify `RUN_KEYS` here: a bounded grep on the minified bundle hit the search tool's complexity limit.
- `plugin/commands/studio.md` is normally synced from the archflow-studio repo. This story's rewrite needs to flow back there, or the next sync will overwrite it.
- Cursor Plugin installs (Customize > Plugins) and a direct `gemini extensions install <github url>` do not carry the bundle. The studio command then reports the bundle missing and points to `npx archflow install`, and the adapter READMEs document the manual copy. This is a documented degrade, not a defect.
