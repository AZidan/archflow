# archflowai

The domain spelling of the [`archflow`](https://www.npmjs.com/package/archflow) package. `npx archflowai install`
does exactly what `npx archflow install` does; this package only depends on `archflow` and runs its CLI.

Archflow: <https://archflowai.dev> - <https://github.com/AZidan/archflow>
